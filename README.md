# Sales EDA & Tableau Dashboard

## Project Overview

This project focuses on analyzing sales data to identify important business patterns, performance trends, and key insights.

The project workflow includes:

*Excel Data Cleaning → Python EDA & Analysis → Tableau Visualization & Dashboard*

## Tools Used

* *Excel* – Data cleaning and data preparation
* *Python* – Exploratory Data Analysis (EDA) and statistical analysis
* *Pandas & NumPy* – Data analysis
* *Tableau* – Data visualization and dashboard

## Data Cleaning

The raw sales dataset was cleaned and prepared using *Excel*. The cleaning process included checking and handling data quality issues such as missing values, duplicate records, inconsistent values, and invalid data.

## Analysis

Python was used to perform:

* Statistical summary
* Product-wise analysis
* Category-wise analysis
* Region-wise analysis
* Channel-wise analysis
* Salesperson analysis
* Monthly sales and profit analysis
* Correlation analysis
* Key business metrics

## Tableau Dashboard

The final interactive dashboard was created in *Tableau* and includes:

* KPI Summary
* Sales by Product
* Category Performance
* Monthly Sales Trend
* Region Performance
* Interactive Filters

## Project Outcome

The project provides a clear view of sales performance and helps identify high-performing products, categories, regions, and sales channels.
